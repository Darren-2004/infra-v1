## 1. Navigation dans le Système de Fichiers

### `pwd` (Print Working Directory)
* **Syntaxe :** `pwd`
* **Description :** Affiche le chemin absolu du répertoire courant.
* **Exemple :**
  ```bash
  pwd
  # Résultat : /home/vagrant
